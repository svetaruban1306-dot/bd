Етап 1: Ознайомлення з LibreOffice Base

📖 Теоретична довідка (Параграф 6.1)

База даних (БД) — це впорядкований за певними правилами набір взаємопов'язаних даних. Для роботи з ними використовують LibreOffice Base (основний формат .odb).

Основні об'єкти в базах даних Base:

  • Таблиці — зберігання даних.
  • Форми — зручне введення та перегляд даних.
  • Запити — вибірка даних за умовами.
  • Звіти — узагальнення та друк.

Ключ-завдання: Який об'єкт БД LibreOffice Base призначений для зручного введення та перегляду відомостей про осіб?

Етап 2: Реляційна структура та Ключові поля

📖 Теоретична довідка (Параграф 6.2)

У реляційній БД:

  • Рядок таблиці — це запис (один об'єкт).
  • Стовпець — це поле (має ім'я та тип даних: Текст, Число, Дата, Грошовий).
  • Ключове поле (ключ) — поле з унікальними значеннями для кожного запису.

Ключ-завдання: Яке поле доцільно обрати як ключове в таблиці «Монітори», якщо назви моделей та ціни можуть повторюватися?

Етап 3: Сортування та Фільтрування даних

📖 Теоретична довідка (Завдання підручника)

Для відбору даних використовують:

  • Сортування: Упорядкування записів за зростанням або спаданням.
  • Типовий (Стандартний) фільтр: Відбір за кількома умовами (оператори І / АБО).
